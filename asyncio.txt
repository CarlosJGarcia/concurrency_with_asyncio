Concurrencia: Dos tareas que se hacen independientemente
Ejemplo:
- Un pastelero mezcla los ingredientes de un pastel mientras se calienta el horno
- Hay dos tareas al mismo tiempo: Mezclar ingredientes y el horno se calienta

Paralelismo: No solo dos tareas se ejecutan independientemente (concurrentemente) sino al mismo tiempo
Ejemplo:
- Dos pasteleros mezclando cada uno los ingredientes de un pastel, cada uno con sus propias herramientas



CPU con 1 Core:
- Tiempo ->
- CPU: Tarea 1 | Tarea 2 | Tarea 1 | Tarea 2
- Concurrencia: Dos tareas que se hacen independientemente. Si solo hay 1 CPU, hay que ir alternando
- Multitasking

CPU con 2 Cores:
- Tiempo ->
- CPU 1: Tarea 1
- CPU 2: Tarea 2
- Paralelismo: Dos tareas que se hacen independientenmente y al mismo tiempo. Requiere 2 CPUs
- Multithreading

Proceso: Elemento del Sistema Operativo que tiene su propio espacio de memoria, aislado del de otros procesos, su propio CPU Core y un PID (Process ID)

Librerías Python
- multiprocessing: Permite crear procesos independientes. Cada proceso tiene su propio espacio de memoria aislado de otros procesos y su propio CPU Core
- threading: Permite creat threads dentro del proceso del programa python
- asyncio: Todo está dentro del mismo proceso y del mismo thread. El código (event loop, usando await) controla qué se está ejecutando

Race condition: When, due to concurency the output of the probram is unpredictable as it depends on the behaviour of the OS scheduler, which depends on the status of the computer, which is different every time that the program is executed.

GIL: Global Interpreter Lock

Asyncio and the GIL: asyncio exploits the fact that I/O operations release the GIL to give us concurrency, even with only one thread.

Coroutine: A Python function that can be paused
async: Python keyword that allows to define coroutines
await: Python keyword that allows to pause coroutines



Define a function
-----------------
def increase(n):
    return n + 1


Define a coroutine
------------------
async def increase(n):
    return n + 1

Run a coroutine. There are two ways.
------------------------------------
asyncio.run(increase(42))

result = await increase(42)
